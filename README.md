# Rocket Powered Goblins (RPG Templates)

**Team 013-2 | DND4ALL**

A modular system to design, share, and use character sheets for any TTRPG you can dream of.

Users build their own templates with drag-and-drop fields like stats, skills, inventories, spell lists, and notes, with calculated values that update automatically. Sheets save to a personal account, and any template can be published to a public library for others to copy and tweak.

> "To provide a community with a Usable, Sharable, Modular system to reduce the complexity of tabletop roleplaying games and make them accessible to consumers."
